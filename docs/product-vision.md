# Product Vision

PeopleSoft Gems is the fastest way for PeopleSoft professionals to find trustworthy technical knowledge and solve real implementation problems.

## Core promise

**Search less. Troubleshoot faster. Verify every answer.**

## Long-term vision

> ERP knowledge is everywhere. PeopleSoft Gems is the interface to it.

## Primary user

Senior PeopleSoft developers and techno-functional consultants working across PeopleCode, Application Engine, Integration Broker, REST, Component Interfaces, SQL, PeopleTools, Campus Solutions, and FSCM.

## V1 focus

The first release should concentrate on:

- PeopleCode
- Integration Broker
- REST APIs
- Application Engine
- Component Interfaces
- Oracle SQL
- PeopleTools

Campus Solutions and FSCM remain part of the taxonomy, but initial content density should be concentrated in the technical areas above.

## Product principles

- Search is the homepage.
- Quality matters more than content volume.
- Original sources stay visible.
- AI should retrieve before it answers.
- Source-backed information and AI interpretation must be distinguishable.
- Version relevance is first-class metadata.
- When evidence is weak, the product should say so.

## MVP

1. Homepage search
2. Gem database
3. Search results
4. Gem detail page
5. Category browsing
6. AI-generated Gem summaries
7. Gem Score
8. Ask PeopleSoft Gems
9. Lightweight admin workflow

## Explicitly not V1

- SAP, Workday, Oracle Fusion, Salesforce
- user profiles and reputation
- comments and community moderation
- enterprise SSO
- mobile apps
- browser extensions
- internet-wide crawling
- paid subscriptions
- custom vector database infrastructure
- fine-tuned LLMs
- complex recommendation systems

## Success condition for the MVP

A PeopleSoft developer should be able to enter a real technical problem, discover a few highly relevant resources quickly, understand why those resources are useful, and receive source-backed troubleshooting guidance without losing access to the original evidence.
